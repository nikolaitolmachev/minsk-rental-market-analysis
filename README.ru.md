# Анализ рынка аренды жилья в Минске

Анализ объявлений о долгосрочной аренде квартир в Минске: цены, влияние расположения и история изменения цен в разных ценовых сегментах.

В анализе используется медиана: распределение цен в объявлениях асимметрично и вытянуто в сторону высоких значений. Небольшое число дорогих квартир слишком сильно влияло бы на среднее арифметическое.

## Основные результаты

* Медианная стоимость аренды в выборке от **28 октября 2026 года** составляет **\$700 в месяц**, а медианная цена за м² — около **\$13.1/м²**. Ниже — медианы по числу комнат.

  | Число комнат | Медианная аренда, USD/мес. |
  | --- | ---: |
  | 1 | 550 |
  | 2 | 700 |
  | 3 | 900 |

---

* В **Центральном районе** самая высокая медианная стоимость аренды — **\$934** в месяц, а в **Октябрьском районе** самая высокая медианная цена за м² — около **\$15.5/м²**.

  | Район | Объявления | Медианная аренда, USD/мес. | Медианная цена за м², USD |
  | --- | ---: | ---: | ---: |
  | Центральный | 332 | 934 | 14.3 |
  | Первомайский | 229 | 713 | 13.3 |
  | Советский | 166 | 708 | 11.9 |
  | Октябрьский | 265 | 668 | 15.5 |
  | Московский | 205 | 657 | 12.6 |
  | Партизанский | 60 | 656 | 12.1 |
  | Ленинский | 88 | 647.5 | 11.2 |
  | Фрунзенский | 217 | 600 | 11.0 |
  | Заводской | 40 | 504.5 | 10.7 |

  Стоимость аренды зависит и от площади квартиры. Поэтому место района в рейтинге зависит в том числе от состава объявлений. Цена за м² дополняет это сравнение.

---

* Для квартир в пределах **5 км от Октябрьской площади** медианная цена за м² выше, чем дальше от неё. Разница — около **18.7%**.

  | Расстояние до Октябрьской площади | Объявления | Медианная цена за м², USD |
  | --- | ---: | ---: |
  | В пределах 5 км | 955 | 14.13 |
  | Дальше 5 км | 669 | 11.90 |

  Расстояние измеряется по прямой от памятника «Нулевой километр» на Октябрьской площади. На сравнение также могут влиять площадь квартир и состав объявлений.

---

* В объявлениях агентств медианная стоимость аренды в месяц выше, чем в частных объявлениях. При этом агентства предлагают более просторные квартиры. Разница в медианной цене за м² меньше — около **5%**.

  | Тип продавца | Объявления | Медианная аренда, USD/мес. | Медианная площадь, м² | Медианная цена за м², USD |
  | --- | ---: | ---: | ---: | ---: |
  | Агентство | 376 | 800 | 63.35 | 13.55 |
  | Частное лицо | 1,248 | 679 | 52.00 | 12.90 |

  По этому сравнению нельзя отделить влияние автора объявления от влияния площади, расположения квартиры и других характеристик.

---

* История цен доступна для **1,585 из 1,624 объявлений** в октябрьской выборке. Из них **832 (52.5%)** содержат хотя бы одно изменение цены. В **61.3%** таких объявлений цена менялась несколько раз. Медианное число изменений — **два на одно объявление**.

---

* В **высоком ценовом сегменте** самая высокая доля объявлений с изменениями цен. Во всех трёх сегментах снижение цены встречается чаще повышения. В **среднем сегменте** разница между долями объявлений со снижением и повышением самая большая.

  | Ценовой сегмент | Текущая стоимость аренды в месяц, USD | Любое изменение цены | Повышение цены | Снижение цены |
  | --- | ---: | ---: | ---: | ---: |
  | Бюджетный | rent ≤ 600 | 45.3% | 29.2% | 35.4% |
  | Средний | 600 < rent ≤ 832 | 53.5% | 31.6% | 44.1% |
  | Высокий | rent > 832 | 59.1% | 39.0% | 47.0% |

  Объявления разделены на три примерно равные по размеру ценовые группы. Доли рассчитаны среди объявлений с доступной историей цен. В истории одного объявления могут быть и повышения, и снижения цены.

---

## Анализ

Проект включает:

* проверку качества данных и приведение категориальных значений к единому виду;
* анализ стоимости аренды по числу комнат и районам;
* сравнение стоимости аренды в месяц и цены за м²;
* анализ расположения квартир по расстоянию от памятника «Нулевой километр» на Октябрьской площади;
* сравнение характеристик квартир и авторов объявлений;
* анализ истории повышений и снижений цен;
* совместный анализ по районам и числу комнат;
* практическое объяснение результатов и рекомендации с учётом ситуации на рынке.

Для проверки устойчивости результатов сравниваются исходные данные и данные после фильтрации выбросов. 
Использованы два статистических метода — IQR и log-MAD. Медианная стоимость аренды остаётся в пределах от **\$679** до **\$700**, а среднее арифметическое сильнее зависит от крайних значений. Объявления, отнесённые к выбросам, сохранены в основном анализе. Без дополнительных сведений о квартирах нельзя уверенно считать необычные цены ошибками данных.

Полный анализ доступен в отдельном файле:

[`minsk_rental_market_analysis.ipynb`](minsk_rental_market_analysis.ipynb)

## Сбор данных

Для основного анализа использованы данные с **Realt.by**, собранные **28 октября 2026 года**. Для сбора данных использован собственный инструмент на Python, включённый в репозиторий.

Октябрьская выборка содержит:

* **1,624 объявления об аренде**
* **4,665 записей истории цен**

Выгруженные CSV-файлы содержат структурированные данные объявлений и историю цен. В них нет контактных данных, фотографий, описаний объявлений и полных адресов.

Октябрьская выборка находится в каталоге `data/`. Первая выборка от **5 сентября 2026 года** также сохранена для сравнения. Обе выборки позволяют воспроизвести анализ без повторного сбора данных.

## Локальный запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/nikolaitolmachev/minsk-rental-market-analysis.git
cd minsk-rental-market-analysis
```

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Запустите JupyterLab:

```bash
jupyter lab
```

## Инструмент сбора данных

Для быстрой проверки соберите небольшую выборку:

```bash
python collect_realt.py --max-ads 10
```

Запустите полный сбор данных:

```bash
python collect_realt.py
```

Сохранённые в репозитории CSV-выборки позволяют воспроизвести анализ без повторного сбора данных.
